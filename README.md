## Cellular Modem Emulator for Accelerating the Development of Embedded Devices

 This modul is about emullation of modem like bg96, for testing your firmware.
U can test by extend python script.

### Run:
```sudo ./emul.py -m bg96 -f your_test_script.py```
**OR**
```sudo ./emul.py```
 
 Without adding parametrs is there short dialog.
